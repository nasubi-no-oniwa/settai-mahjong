# 接待麻雀

部長が、海底で白を切る。その白で、自分（大三元）も部下（国士無双）も女同僚（四暗刻単騎）も役満。さあ、どうする？ エンドは全部で11種類。

- 遊ぶ：https://nasubi-no-oniwa.github.io/settai-mahjong/
- 公開：2026/11/13 18:00（日本時間）。それまでは、リンクを開いても予告だけが出る（`main.js` の `REL`）。確認用の合鍵つきのリンク（`?pre=…`）なら先に遊べる
- 「11/13 20:00 にリプ欄で回答発表」の文は、20:00 に自動で消える（`main.js` の `HIDE`）

## 流れ
1. ムービー（自分→部下→女同僚→部長の順に最後のツモ。2回目からは倍速。スキップあり）
2. 部長が白を持って迷う3秒（このあいだだけ、部長をさわれる）
3. 白が切られる。「ロン」ボタンは5秒だけ出る（このあいだ、白・女同僚・明かり・窓・卓をさわれる）
4. エンドの演出 → 結果（ランク・何人目か・見つけた人数・見つけたエンドの数）

## 麻雀の中身
- 東家（親）＝女同僚、南家＝部長、西家＝自分、北家＝部下。鳴きなしで進むと、海底（70枚目）は南家の部長に来る
- 白は4枚ちょうど：部長の海底1枚、自分の手に2枚、女同僚の手に1枚（部下の国士は白だけ足りない形）
- あがる順：大三元（自分）→ 四暗刻単騎（女同僚）→ 国士無双（部下）
- 点数：大三元 32,000＋四暗刻単騎（親のダブル役満）96,000＋国士無双 32,000＝部長の支払い 160,000点（25,000 → −135,000）

## ファイル
- `index.html`（画面・広告・記録のかたまり）、`main.js`（流れ・操作・通信・動画）、`acts.js`（場面。どれも「場面が始まってからの秒」だけで絵が決まる）
- `world.js`（3Dの部屋・卓・牌・人）、`fx.js`（重ねる2Dの絵）、`snd.js`（音）、`tx.js`（ことば 4言語）
- ファイルどうしは `?v=番号` をつけて読みこむ。直したら、全部の番号をそろえて上げる
- Firebase：ft-red の `settaimj` の下（`database.rules.settaimj.json` を上げると自動で反映。鍵は `FT_RED_SERVICE_ACCOUNT`）
  - `c`＝エンドごとの「見つけた人数」と制覇した人数（数だけ。1人1エンド1回）、`u`＝数えた印、`x`＝引き継ぎコード
- 記録：見つけたエンドと「何人目か」は、遊ぶ人のブラウザの中（`sm_s`）。引き継ぎコード（8文字）で別のブラウザへ移せる
- 広告：結果画面とタイトル画面（なすびのお庭の決まりどおり。スマホだけ）。`?adcheck=1` で広告の枠の様子を字で出す。`?noad=1` で広告なし
- 試験：`test/rules-test.mjs`（ルール。GitHub の上で動く）。`index.html?test&step` で通信なし・手動で時間を進める形になる（`window.__SM`）
